# FlowMaster 3D

Create a modern, professional frontend prototype called “3D Water Flow Simulator” exactly as described. Build the dark GIS/scientific dashboard with responsive React/TypeScript/Tailwind UI, a convincing interactive Three.js 3D mountainous terrain as the main focus, selectable dam marker and popup, animated cyan water flowing downhill on start, configurable simulation controls, bottom timeline, collapsible live statistics panel, header/nav, and floating map controls. Use realistic supplied demo values, mock all terrain and hydrology calculations, and make interactions functional: terrain click selection, use as dam, sliders/inputs, start/pause/resume/reset, speeds, visualization toggles. Organize into reusable components and use Lucide icons.
